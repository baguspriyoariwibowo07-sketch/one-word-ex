A single one-word entry, written by `main.ts` to `/output/entry.txt` — nothing else.

## The word

> Rebound

## Why this word

- **The sting nobody used:** the smallest field in the batch saturates with Practice (three entries), Almost (three), Placeholder, Exhausting, Forgettable, Potential, Unfinished and Deprecated. "Rebound" is unclaimed.
- **Painfully honest, not just mean:** an insult can be argued with. A role cannot. It says you were never the destination — you were the in-between after the real one, and everyone reading it has either been it or used one.
- **It cuts both ways:** it describes you, and it quietly convicts the ex, who was still comparing everyone to the person before. That second edge is what makes a stranger laugh and wince at once.
- **Tight:** 7 characters against the 1–24 gate, exactly one word.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
